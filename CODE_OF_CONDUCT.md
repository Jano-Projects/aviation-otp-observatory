# Code of conduct

This is an open project about public flight data. Everyone who takes part (issues, pull requests or any other project space) agrees to:

- treat others with respect, with no insults, personal attacks, harassment or discrimination of any kind;
- discuss ideas and code, not people, and accept and give constructive criticism;
- be patient with newcomers to Oracle, data engineering or aviation;
- never publish personal data or credentials of others;
- not use the project for advertising or spam.

## Reporting

Contact the maintainer privately through the [security policy](SECURITY.md) channel ("Report a vulnerability"), even for problems that are not technical.

Comments, issues or contributions that break this code may be edited, hidden or removed, and repeated offenders may be blocked from the project.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.
